## 🔭 What I work on

- **[AugmenTest](https://www.khandakerrahin.com/developer/projects/)**: generates test assertions with LLMs from a method's documentation and comments, without reading its implementation.
  Papers at [ICST 2025](https://doi.org/10.1109/ICST62969.2025.10988926) and in [Science of Computer Programming (2026)](https://doi.org/10.1016/j.scico.2026.103531) · [replication package](https://doi.org/10.5281/zenodo.13881826)
- **[EvoOracle](https://github.com/khandakerrahin/evooracle)**: LLM-generated test oracles on top of EvoSuite tests (my M.Sc. thesis, University of Trento).
- **Model-based testing** of railway interlocking systems ([ISoLA 2024](https://doi.org/10.1007/978-3-031-75390-9_8)).
- **Interactive optimisation of system configurations** using feature models (QUATIC 2026).

All publications: **[khandakerrahin.com/developer/publications](https://www.khandakerrahin.com/developer/publications/)**
